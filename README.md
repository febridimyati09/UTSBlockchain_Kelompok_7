# 🎓 Sistem Verifikasi Sertifikat & Ijazah Digital Berbasis Blockchain

Proyek ini merupakan **Tugas Ujian Tengah Semester (UTS)** Mata Kuliah **Teknologi & Rekayasa Blockchain (Berbasis Proyek)**. Aplikasi ini dirancang sebagai prototipe *Smart Contract* v1.0 menggunakan bahasa pemograman Solidity untuk menerbitkan dan memverifikasi keaslian ijazah/sertifikat akademik secara terdesentralisasi dan bebas dari pemalsuan data.
